# AI-Powered Fake Review Detection System

This project aims to detect fake and misleading reviews in e-commerce platforms using Artificial Intelligence and Machine Learning.

---

## 🎯 Goal

Fake reviews created by bots and automated systems manipulate user decisions and damage trust.

This project aims to:

- detect fake reviews,
- improve trust in e-commerce,
- build a scalable AI system.

---

## ⚙️ System Architecture

### 1. Review Collection ✅
- Collects review data
- Supports resume, retry, and team-based execution

### 2. Data Processing 🔄
- Data cleaning
- Feature extraction
- Dataset preparation

### 3. AI / ML System 🚀
Models:
- Naive Bayes
- SVM
- Random Forest
- K-Means
- LSTM
